# 星海寄願所｜綠色星海 3D 版本

這是可直接預覽的網站起始專案，已改為綠色系星空與 3D 建模風格的傳統天燈。

## 目前包含
- 深綠、鼠尾草綠與柔和暖金色星海介面
- Three.js 製作的 3D 傳統天燈模型（可拖曳旋轉、漂浮）
- 傳統天燈配色選擇
- 自由繪製圖案並貼合到天燈模型表面
- 暱稱與祝福留言
- 本機瀏覽器保存與祝福卡片展示

## 重要：目前保存方式
此版本先使用瀏覽器 localStorage，因此留言只會留在目前這台裝置、目前這個瀏覽器。其他粉絲還看不到彼此的天燈。要變成全站共享，需要下一步接 Cloudflare Pages Functions + D1，並設定資料庫、管理員審核及備份。

## 免費部署方向
1. 將這個資料夾內的檔案上傳到 GitHub repository。
2. 在 Cloudflare Pages 建立專案並連接 GitHub。
3. Framework preset 選 None，Build command 留空，輸出目錄設為 `/`（若 Cloudflare 介面要求不同，依目前介面設定）。
4. 使用 Cloudflare 提供的 `pages.dev` 免費子網域，不必購買自訂網域。

## 注意
- Three.js 由 jsDelivr CDN 載入，因此首次開啟需要網路。
- 免費服務有使用額度、政策及服務可用性限制；不能保證永遠不中斷。
- 請勿在公開留言收集真實姓名、電話、住址、學校或帳號密碼。
- 上線前建議增加垃圾留言防護、檢舉與管理員審核。
